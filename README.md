# Evidence Dot

小红书投资内容 AI 证据点 Demo。它现在有两种使用方式：

1. **下载即用桌面版**：打开 `dist\Evidence-Dot-1.0.0-x64.exe`，不需要安装 Node、不需要运行命令。
2. **开发调试版**：在项目目录运行 `npm run desktop`。

## 下载即用版本

已生成 Windows 便携版：

```text
C:\Users\frank\.codex\xhs-evidence-demo\dist\Evidence-Dot-1.0.0-x64.exe
```

项目根目录也有一个快捷方式：

```text
C:\Users\frank\.codex\xhs-evidence-demo\Evidence Dot Portable.lnk
```

使用者拿到这个 exe 后，直接双击打开软件，在「分析工作台」里填写：

- API Key
- Model，例如 `deepseek-chat`
- Base URL，例如 `https://api.deepseek.com`

然后粘贴任意投资相关内容，点击「分析这段内容」，即可调用模型分析。页面会把这些设置只发送到软件内置的本地接口 `/api/analyze`，不需要用户配置本地环境变量。

如果模型调用失败，Demo 会自动使用本地规则兜底，保证演示不中断。

## 产品结构

- 「真实交互体验」：类小红书阅读界面，点击正文里的证据点后才出现 AI 判断弹窗。
- 「分析工作台」：自定义输入、API 设置、行为画像 Skill。自定义输入分析完成后会自动生成一篇类小红书帖子，并把关键字段转成可点击证据点。
- 「产品逻辑与理论」：产品原则、浏览/兴趣/研究状态、技术面/基本面偏好、行为金融依据。

## 新版演示主线

打开软件后默认进入「真实交互体验」：

1. 在顶部输入任意投资笔记，或点击「一键演示」。
2. 软件生成一篇类小红书帖子。
3. 正文里的证据点会按语义分为数据核验、情绪风险和生成痕迹。
4. 用户点击证据点后，AI 判断层才出现。
5. 切换模拟用户画像后，同一个证据点会按浏览态、兴趣态或研究态展示不同深度。

帖子会包含关注按钮、互动数据和模拟评论区，用来更接近真实小红书阅读场景。

在「分析工作台」里也可以手动修改用户状态和历史偏好，用于演示不同用户画像下同一内容的输出差异；行为画像 Skill 则保留为根据浏览记录、帖子和评论自动判断的入口。

## 核心能力

- 识别事实数据、投资观点、情绪经验、行动号召、教育科普等内容类型。
- 判断证据状态、情绪倾向、生成式表达痕迹、真实经验信号。
- 根据用户行为画像判断浏览态、兴趣态、研究态。
- 根据历史浏览、帖子和评论判断技术面、基本面或混合风格。
- 为不同用户状态和偏好展示不同深度的指标、来源与争议追踪。
- 保留小红书真实经验和情绪共鸣价值，不把所有内容粗暴变成投资建议。

## 本地开发

```powershell
cd C:\Users\frank\.codex\xhs-evidence-demo
npm install
npm run desktop
```

浏览器版：

```powershell
npm start
```

然后打开：

```text
http://localhost:4173
```

## 打包

生成 Windows 便携版：

```powershell
npm run build:win
```

生成未压缩应用目录：

```powershell
npm run pack:win
```

打包产物会输出到 `dist`。
